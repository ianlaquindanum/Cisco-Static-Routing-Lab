# Cisco-Static-Routing-Lab

## Objective
Configure Static routing between three routers

## Technologies
- Cisco Packet Tracer
- Cisco Routers
- Static Routing
- IPv4 Addressing
## Skills Demonstrated
- Network topology design
- IP addressing and subnet configuration
- Connectivity testing using ping
## Result
- Succesfully configured static routes to all routers
